# For Shruti. Obviously.
Cinematic dark-academia / old-money birthday website.

Upload the contents of this folder to the root of your GitHub repository: index.html, style.css, script.js, and assets/. Do not nest them inside another folder.

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root) → Save.

The MP3 loops and the site attempts to start it on the first click anywhere. Browsers may require a click before audio playback. There is no visible play/pause button. Only Shruti's striped-top photo is included. Travel photography loads from Unsplash and requires internet access.
